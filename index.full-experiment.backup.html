Experiment Instructions

This study examines how bilingual students judge the authorship of English texts and how different text types affect second-language memory.

Task 1

Measures intuitive authorship perception: human-written, AI-generated, hybrid, or uncertain.

Task 2

Measures psycholinguistic cues such as fluency, structure, emotion, and personal voice.

Task 3

Measures L2 text memory and working-memory encoding after reading each English passage.

Before you begin

This full version uses multiple short passages. During the trial pages, the interface will show only the text, required questions, and response options so that extra instructions do not distract the participant.

The experiment randomizes passage order and records keyboard reaction times, accuracy, timestamps, and condition variables for each trial.

Data are anonymous and used only for classroom research. This participant page does not show researcher settings, API prompts, source labels, or debugging information.
